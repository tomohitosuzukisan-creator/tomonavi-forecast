# 需要予測おためしツール(tomonavi)

CSVをアップロードするだけで、売上や客数などの**需要予測をブラウザで試せる無料ツール**です。
中小企業の現場の方が「自社のデータでAI予測が使えそうか」を確かめるための、入り口として作っています。

- 提供: [tomonavi](https://tomonavi.com/)(中小企業診断士 鈴木智仁)
- 料金: 完全無料・ログイン不要
- **アップロードされたデータは保存しません**(処理はその場で行い、終了後に破棄されます)

## このツールの考え方

高精度をうたうツールではありません。むしろ逆で、**「あなたのデータでAIを使う意味があるかどうか」を正直に示すこと**を重視しています。

- **データ品質診断** — 件数が足りない、変動が小さい、ゼロが多いなど、予測に向かないデータを事前に指摘します
- **単純な方法との比較** — AIの予測を「単純平均」「直前の値をそのまま使う」予測と比べ、**AIが勝てていない場合は正直にそう表示します**
- **断定しない** — 予測は過去データのパターンから機械的に計算したものです。「高精度」「これで大丈夫」とは言いません

需要予測は、データが貯まっていなければ機能しません。使ってみて「うまくいかない」と分かることにも価値がある、という設計です。

## 使い方

1. CSVをアップロードする
2. 日付の列と、予測したい数量の列(売上・客数など)を選ぶ
3. 「予測する」を押す

日付と数量の**2列だけでも動きます**。粒度(日次・週次・月次)は自動で判定します。

`sample_data/` に動作確認用のサンプルCSVを置いています。手元にデータがなくても試せます。

| ファイル | 内容 |
|---|---|
| `sample_orders_daily.csv` | 日次546日分の受注件数。曜日・月・月末の傾向がはっきりしたデータの例(時系列予測用) |
| `sample_bento_daily.csv` | お弁当屋さんの平日販売データ約9か月分。メニュー・天気・曜日などの手がかり列つき(要因分析モード用) |
| `sample_small_25rows.csv` | 25行と少なめ。データが足りない場合の診断表示を確認できる例 |

アプリの入口にある2つのボタンから、どちらのサンプルも1クリックで読み込めます。

## 受け付けるデータの上限

処理時間とメモリを抑えるため、次の上限を設けています。無料で公開しているツールとしての現実的な線引きで、上限を超えた場合はエラーメッセージで理由をお伝えします。

| 項目 | 上限 | 理由 |
|---|---|---|
| ファイルサイズ | 5MB | 読み込み前に判定し、大きなファイルでメモリを圧迫しないため |
| 行数 | 5,000行 | 日次で約13年分。中小企業の実務で扱う期間としては十分 |
| 列数 | 20列 | これ以上は「どの列を使うべきか」の判断自体が相談の領域 |
| 一度に使う手がかり | 10列 | 多すぎると「どれが効いているか」が読み取れなくなるため |

## ローカルで動かす

```bash
python -m venv .venv
.venv/Scripts/activate        # Windows
# source .venv/bin/activate   # macOS / Linux

pip install -r requirements.txt
streamlit run app.py
```

## テスト

```bash
pip install -r requirements-dev.txt
python -m pytest
```

`tests/` に43件のテストがあります。Streamlitをダミーに差し替えて読み込み、画面を描かずに計算部分だけを検証する作りです(`tests/conftest.py`)。

過去に実際に起きた不具合は、再発防止のテストとして残してあります。

- 比較基準が最終1点だったため、月末と週末を比べて実態のない大幅減を表示した件
- pandas 3.x で文字列列の判定が変わり、テキスト列を含むCSVで要因分析が動かなかった件
- CSVの並び順によって「未来のデータで学習して過去を当てる」が起こり得た件
- 小規模データでモデルが分岐を作れず、手がかりの効き具合が全ゼロになった件

## 技術構成

- [Streamlit](https://streamlit.io/) — 画面
- [LightGBM](https://lightgbm.readthedocs.io/) — 予測モデル(勾配ブースティング)
- pandas / numpy / matplotlib / scikit-learn

予測はラグ特徴量・移動平均・カレンダー特徴量(曜日・月・四半期など)を作り、LightGBMで学習して再帰的に先の期間を予測します。移動平均は情報の先読み(リーク)を避けるため、1期ずらしてから計算しています。
